# 平台基础

Web API 运行在浏览器提供的宿主环境中。理解执行环境、异步调度和通用接口之后，再学习某个具体 API，会更容易判断它在哪里可用、如何组合以及什么时候需要释放资源。

## 执行环境

- `Window` 对应页面主线程，可以访问 DOM 和用户界面。
- Worker 拥有独立的全局环境和事件循环，不能直接操作 DOM。
- Service Worker 位于页面和网络之间，具有独立的安装、激活和终止生命周期。
- Worklet 面向渲染、布局或音频管线中的小型低延迟任务。

各环境通过全局对象暴露能力。不要仅凭接口名称判断它是否可用，应查看规范中的暴露范围和浏览器兼容性。

## 异步调度

浏览器使用事件循环协调脚本、用户交互、网络和渲染。任务执行结束后会清空微任务队列，然后浏览器才有机会进行渲染。Promise 回调属于微任务，定时器和大部分事件回调属于任务。

这意味着“异步”不等于“并行”。页面主线程上的长任务仍会阻塞输入响应和渲染，计算密集型工作应考虑拆分任务或交给 Worker。

## 通用能力

| 能力 | 作用 |
| --- | --- |
| `EventTarget` / Event | 订阅并分发状态变化 |
| Promise | 表达一次性的异步结果 |
| `AbortController` / `AbortSignal` | 在多个 API 之间传递取消信号 |
| Streams | 渐进读取、转换和写入数据 |
| URL / URLSearchParams | 解析和构造 URL |
| Blob / File / ArrayBuffer | 表达二进制数据和文件 |
| 结构化克隆 | 在 Worker、IndexedDB 等场景复制复杂数据 |

这些能力会被网络、存储、媒体和后台任务反复使用，是不同分类之间的连接点。
